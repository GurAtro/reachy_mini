# docs — 구현 작업 노트

이 폴더 자체가 Obsidian 보관소(vault)입니다.
Obsidian → **폴더를 보관소로 열기** → `Reachy/docs`

먼저 열 노트: **`구현 목록.md`**

앞으로 구현할 기능을 `T-###` 노트 하나씩으로 관리합니다. `구현 목록`의 표는
[Dataview](https://github.com/blacksmithgu/obsidian-dataview)가 각 노트의 프론트매터에서
자동으로 만듭니다 — 목록을 따로 손볼 필요가 없습니다.

> 이 저장소는 **public**입니다. 키나 개인 메모는 넣지 마세요.
