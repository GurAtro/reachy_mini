# T-003 비동기 모션

모션이 블로킹이라 대화 흐름을 막습니다. 증상은 **말 첫머리가 잘리는 것** — 모션이
끝나야 녹음이 시작됩니다. 지금은 `reachy.motion_duration: 0.3`으로 줄여 회피하는데,
그러면 동작이 딱딱해집니다.

## 무엇을 바꾸나

- `reachy/robot.py`의 `_goto()`를 별도 스레드로
- `main.py`에서 모션 완료를 기다리지 않도록 호출부 정리

## 정해야 할 것

**모션이 겹치면?** 이전 모션이 끝나기 전에 다음이 오는 경우.
- 상태 포즈(`idle` / `listening` / `speaking`) → 최신 것만 남기기
- 감정 모션(`nod` / `happy` …) → 완주가 자연스러움

**종료 처리.** `disconnect()` 시점에 스레드가 살아 있으면 하드웨어 반환이 꼬입니다.

**SDK가 스레드 안전한지 확인되지 않았습니다.** 먼저 확인하세요.

## 완료 조건

- [ ] 모션 호출이 즉시 반환
- [ ] `motion_duration: 0.6`에서도 말 첫머리가 안 잘림
- [ ] 종료 시 스레드 정리 후 `disconnect()`
