# R-동작 특성

버그는 아니지만 모르면 버그로 오해하는 것들. **왜 그런지**까지 적어 둡니다.

## 말하기 자세가 실제 발화보다 먼저 잡힙니다
`robot.speaking()`이 LLM 호출 *전에* 불립니다. 그래서 생각하는 동안에도 말하는 자세를
유지합니다. 어색하면 [[M-main 대화 루프]]에서 TTS 직전으로 옮기거나, 별도의 "생각 중"
포즈를 만드세요. → [[M-robot 로봇 제어]]

## 첫 턴만 느립니다
Whisper 모델 로딩과 프롬프트 캐시 생성 때문입니다. 두 번째 턴부터는 시스템 프롬프트와
도구 정의가 캐시에서 읽혀 입력 비용도 크게 줍니다. → [[M-stt 음성 인식]], [[M-llm 언어모델]]

## 말하는 동안에는 듣지 않습니다
순차 처리라 에코는 잘 안 생기지만, 말을 끊고 들어갈 수 없습니다. 의도된 단순화입니다.
→ [[T-004 에코 캔슬레이션과 barge-in]]

## 대화 기록은 20턴에서 잘립니다
그보다 앞의 맥락은 모델이 기억하지 못합니다. 잘렸다는 표시가 어디에도 안 남는 게
문제입니다. → [[M-conversation 대화 기록]]

## edge-tts는 텍스트를 Microsoft 서버로 보냅니다
인터넷이 필요하고, 로봇이 말할 내용이 외부로 나갑니다. 신경 쓰이면 `tts.backend: qwen`.
LLM까지 오프라인으로 가려면 `llm.backend: ollama`도 함께. → [[ADR-002 TTS 기본값을 edge-tts로]]

## 로봇 연결 실패가 조용합니다
mock으로 강등되어도 앱은 정상처럼 보입니다. `[Reachy] Connected.` 로그로만 구분됩니다.
→ [[ADR-003 연결 실패 시 mock 폴백]]
