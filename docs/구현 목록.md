# 구현 목록

```dataview
TABLE WITHOUT ID
  file.link AS 작업,
  priority AS 순위,
  status AS 상태,
  join(files, ", ") AS 파일
FROM "" AND !"_templates"
WHERE status
SORT priority ASC
```

## 순서

1. **[[T-005 Claude API 실호출 검증]]** — 다른 무엇보다 먼저. 기본 백엔드가 미검증입니다.
2. **[[T-001 로봇 모션을 LLM 도구로 노출]]** — 코드량 대비 체감 변화가 가장 큼
3. [[T-003 비동기 모션]] — 말 첫머리 잘림의 근본 원인
4. [[T-002 머리 pitch roll 추가]] — 실기 없이는 막혀 있음
5. [[T-004 에코 캔슬레이션과 barge-in]] — 구조 변경이 큼

## 새 작업 추가

`Cmd+P` → `Insert template` → `구현 작업`

`status`는 `todo` · `in-progress` · `blocked` · `done`,
`priority`는 `P0` · `P1` · `P2` · `P3` 중 하나만 씁니다. 오타가 나면 위 표에서 사라집니다.
