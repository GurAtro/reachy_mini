# T-003 비동기 모션

## 왜 하는가
모션이 블로킹이라 대화 흐름을 막습니다. 증상은 **말 첫머리가 잘리는 것** — 모션이
끝나야 녹음이 시작됩니다. 지금은 `motion_duration: 0.3`으로 줄여 회피하고 있는데,
그러면 동작이 딱딱해집니다.

## 무엇을 바꾸는가
- `reachy/robot.py`의 `_goto()`를 별도 스레드로
- `main.py`에서 모션 완료를 기다리지 않도록 호출부 정리

## 짚어야 할 문제
- **모션 중첩**: 이전 모션이 끝나기 전에 다음이 오면? 큐로 쌓을지, 최신 것만 남길지 결정 필요. 상태 포즈(`idle`/`listening`/`speaking`)는 최신 것만, 감정 모션은 완주가 자연스럽습니다.
- **종료 처리**: `disconnect()` 시점에 스레드가 살아 있으면 하드웨어 반환이 꼬입니다.
- SDK가 스레드 안전한지 확인되지 않았습니다.

## 완료 조건
- [ ] 모션 호출이 즉시 반환
- [ ] 말 첫머리 잘림이 `motion_duration: 0.6`에서도 사라짐
- [ ] 종료 시 스레드 정리 후 `disconnect()`

## 검증 방법
mock 모드로 타이밍 로그만 봐도 1차 확인 가능. 실제 잘림 여부는 실기에서.
